# Shopwell JavaScript Code Quality

This repository is a monorepo for ESLint and Stylelint rules for Shopwell.

## Packages

- [`@shopwell-ag/admin-eslint-rules`](./packages/admin-eslint-rules/) - ESLint rules for the Shopwell Administration
- [`@shopwell-ag/storefront-eslint-rules`](./packages/storefront-eslint-rules/) - ESLint rules for the Shopwell Storefront
- [`@shopwell-ag/admin-stylelint-rules`](./packages/admin-stylelint-rules/) - Stylelint rules for the Shopwell Administration
